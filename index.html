Nomatron Releases

Download Nomatron binaries, Linux packages, and container images.

Install

  • apt: deb [signed-by=/usr/share/keyrings/nomatron.gpg] https://packages.nomatron.io/apt stable main (GPG key)
  • yum/dnf: https://packages.nomatron.io/rpm/stable/ (GPG key)
  • Container images: ghcr.io/nomatronio/nomatron-releases/nomatron and ghcr.io/nomatronio/nomatron-releases/nomatron-agent
  • Homebrew: nomatronio/homebrew-tap
  • GitHub Releases: nomatronio/nomatron-releases
